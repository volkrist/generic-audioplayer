What is Generic AudioPlayer?

Generic AudioPlayer is an Android music player designed for offline audio playback. It uses modern Android technologies and focuses on practical listening features: library browsing, queue management, playback controls, equalizer settings, bass boost, virtualizer, sleep timer and persistent playback state.

The project is suitable as a portfolio-level Android audio application and as a base for further improvements in music player UX, MediaStore scanning, local playback, widgets, notifications and audio effects.
